# Automatic Pivot Table Generator

An Excel VBA automation tool that generates a Pivot Table automatically.

## Features
- Select source data dynamically.
- Automatically identifies the first numeric column.
- Uses the first column as the Row field.
- Creates a new Pivot Table worksheet.
- Applies professional Pivot Table formatting.

## Installation
1. Download the BAS module.
2. Open Excel and press ALT + F11.
3. Select File > Import File.
4. Import AutomaticPivotTableGenerator.bas.
5. Run GenerateAutomaticPivotTable.

## Requirements
- Microsoft Excel desktop.
- Source data with column headers.
- At least two columns and two rows.
